## ☁️ About Me

> **Enterprise Cloud Operations • Modern Workplace Engineering • Security-First Automation**

I am a **Microsoft 365 Administrator** with **4+ years of hands-on experience** managing, securing, and automating enterprise cloud environments. My core focus lies in architecting resilient modern workplaces, enforcing device compliance across corporate endpoints, governing hybrid identities, and eliminating manual operational overhead through modular PowerShell and Microsoft Graph automation.

- 🏢 **Primary Role:** Microsoft 365 Administrator (`Exchange Online` • `Intune` • `Entra ID` • `Defender` • `SharePoint`)
- 🛡️ **Operational Focus:** Zero Trust identity posture, silent endpoint deployment & patching, vulnerability remediation, and tenant-wide security auditing.
- ⚙️ **Automation Philosophy:** Building silent, self-healing PowerShell frameworks and Microsoft Graph API reporting tools that enhance both security compliance and end-user experience.
- 🎯 **Career Ambition:** Advancing toward **Senior M365 Engineer** and **Microsoft 365 Architect** roles—designing scalable, high-availability enterprise cloud ecosystems.
