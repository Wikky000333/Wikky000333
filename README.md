## 👨‍💻 About Me

I'm **Vignesh A (Wikky)**, a Microsoft 365 Administrator with **4+ years of experience** in enterprise IT administration, endpoint management, identity, messaging, and cloud security.

I enjoy building practical automation that reduces repetitive administration, improves compliance, and makes enterprise environments easier to manage.

- 🏢 **Domain:** Microsoft 365 Administration
- 📧 **Messaging:** Exchange Online, Exchange Hybrid & mail flow
- 💻 **Endpoint Management:** Microsoft Intune, Windows Autopilot & patch management
- 🔐 **Identity:** Microsoft Entra ID, Active Directory & hybrid identity
- 🛡️ **Security:** Microsoft Defender, vulnerability management & KQL
- ⚙️ **Automation:** PowerShell, Microsoft Graph API & Intune Remediations
- 🎓 **Certification:** Microsoft Certified: Endpoint Administrator Associate (MD-102)
- 🌱 **Currently learning:** Advanced Graph automation, cloud security & Microsoft 365 architecture
- 🎯 **Career goal:** Senior Microsoft 365 Engineer → Microsoft 365 Architect
