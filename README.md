## 👋 About Me

Hi, I'm **Vignesh A (Wikky)**, a Microsoft 365 Administrator with **4+ years of experience** in enterprise Microsoft 365 administration, endpoint management, identity, messaging, and infrastructure operations.

I focus on making enterprise IT more efficient through PowerShell automation, proactive troubleshooting, security improvements, and reliable endpoint management.

- 🏢 **Primary domain:** Microsoft 365 Administration
- 📧 **Messaging:** Exchange Online, Exchange Hybrid, mail flow and troubleshooting
- 💻 **Endpoint management:** Microsoft Intune, Windows Autopilot and update management
- 🔐 **Identity:** Microsoft Entra ID, Active Directory and hybrid identity
- 🛡️ **Security:** Microsoft Defender, vulnerability management and KQL
- ⚙️ **Automation:** PowerShell, Microsoft Graph API and Intune Remediations
- 🎓 **Certification:** Microsoft Certified: Endpoint Administrator Associate (MD-102)
- 🌱 **Currently learning:** Advanced Graph automation, cloud security and M365 architecture
- 🎯 **Career goal:** Senior Microsoft 365 Engineer and Microsoft 365 Architect

> My approach: automate repetitive tasks, strengthen security, improve compliance, and build maintainable solutions for enterprise environments.
